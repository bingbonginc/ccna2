A: /64 + 3 bits = /67  (5 butas, 1st Hex, 2i)
I:
	fd00:0001:0000:0000:0000:0000:0000:0000
		1st office:    :0000:
		2nd office:    :2000:
		3rd office:    :4000:
		up to 
		8 office:      :e000:

ex 2: Subnet for 4 offices using network address fd00:2::/88
using the 3rd office:
	apply the 1st valid ip on R1
	apply the last valid ip on R2
C: 4 offices = 2 bits
A /88 + 2 bits = /90 (6th butas, 3rd hex, 4i)
I:
	fd00:0002:0000:0000:0000:0000:0000:0000
						1st :0000
							:0040
							:0080
				  4th office:00C0
		
3rd office network: fd00:0002:0000:0000:0000:0080:0000:0000 /90
First valid ip add: fd00:0002:0000:0000:0000:0080:0000:0001 /90 //plus 1 network
Last valid ip add:  fd00:0002:0000:0000:0000:00bf:ffff:ffff /90 //minus 1 network
not network: 		fd00:0002:0000:0000:0000:00c0:0000:0000 /90

 Determine the 3rd subnet
 
 2 raise 2 to get the bits //ipv6 only

 I:

											 :0010:
											 :0020:
											 :0030: //not net

	non any:	fd00:0004:0000:0000:0000:0000:002f:ff7f /108  //non any = 7f last 2, constant no change
	first any:	fd00:0004:0000:0000:0000:0000:002f:ff80 /108  //non any = 80 last 2 , constant no change
	last any:	fd00:0004:0000:0000:0000:0000:002f:ffff /108
